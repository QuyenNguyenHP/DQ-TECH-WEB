SSH - Secure Shell

SSH cho phép quản trị server từ xa an toàn, mã hóa toàn bộ dữ liệu truyền. Bài học này giúp bạn hiểu SSH hoạt động ra sao và cách xác thực bằng password hay SSH key.

Khái niệm

SSH là gì?

📖 Định nghĩa

SSH là giao thức truy cập và quản trị thiết bị từ xa một cách an toàn.

🧭 Đặc điểm
  • Hoạt động ở Application Layer.
  • Dùng TCP port 22.
  • Mã hóa toàn bộ dữ liệu truyền.
✅ SSH dùng để
  • Đăng nhập server từ xa.
  • Thực thi lệnh quản trị.
  • Truyền file qua SCP/SFTP.
  • Tunneling/port forwarding.

Nguyên lý

Quy trình kết nối SSH

1. Kết nối Client gửi yêu cầu đến server.
2. Xác thực Server gửi public key, client xác thực.
3. Mã hóa Hai bên tạo khóa phiên và trao đổi dữ liệu đã mã hóa.

Xác thực

Password vs SSH Key

Password

  • Dễ dùng, dễ triển khai.
  • Kém an toàn hơn.
  • Dễ bị brute force nếu quản lý kém.

SSH Key

  • Không gửi mật khẩu qua mạng.
  • An toàn, chuyên nghiệp.
  • Chuẩn doanh nghiệp hiện đại.

Kỹ thuật

Thông số cần nhớ

SSH Key

  • Public Key: đặt trên server.
  • Private Key: giữ bí mật ở client.
  • Không bao giờ chia sẻ private key.

SSH vs Telnet

  • SSH mã hóa, Telnet không.
  • SSH bảo mật cao, Telnet lỗi thời.
  • SSH port 22, Telnet port 23.

Công cụ phổ biến

  • Linux/macOS: ssh.
  • Windows: OpenSSH, PuTTY.
  • GUI: MobaXterm, SecureCRT.

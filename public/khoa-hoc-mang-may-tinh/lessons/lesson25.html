Cấu hình động với DHCP

DHCP là lý do bạn cắm mạng là có Internet ngay. Bài học này giúp bạn hiểu quy trình cấp IP tự động và cách quản lý địa chỉ trong mạng LAN.

Khái niệm

DHCP là gì?

📖 Định nghĩa

DHCP tự động cấp phát cấu hình mạng cho thiết bị.

🧭 Vận hành
  • Hoạt động tại Application Layer.
  • Sử dụng UDP port 67/68.
  • Thường nằm trên router hoặc server.
✅ DHCP cấp
  • IP Address, Subnet Mask.
  • Default Gateway.
  • DNS Server.
  • Lease Time.

Nguyên lý

Quy trình DORA

Discover Client broadcast tìm DHCP Server.
Offer DHCP Server đề xuất IP.
Request Client yêu cầu IP được đề xuất.
ACK Server xác nhận và cấp IP.

Cấu hình

Lease time và kiểu cấp phát

Lease Time

  • IP không vĩnh viễn.
  • Gần hết hạn sẽ tự gia hạn.
  • Hết hạn sẽ thu hồi IP.

Kiểu cấp phát

  • Dynamic: IP thay đổi theo thời gian.
  • Automatic: IP cố định sau lần đầu.
  • Reservation: IP cố định theo MAC.

Reservation

  • Dùng cho máy in, server, camera.
  • Quản lý dễ, IP không đổi.

Ví dụ

Case study: mạng văn phòng nhỏ

🏢 1 router, 20 máy tính, 2 máy in.

🔁 Máy tính dùng DHCP động.

🖨️ Máy in dùng DHCP reservation.

✅ Quản lý dễ, không trùng IP.

Kết luận:

DHCP giúp mở rộng mạng nhanh và quản lý hiệu quả.

  1. Kiểm tra cấu hình IP hiện tại.
  2. Xác định IP có phải DHCP cấp không.
  3. Tìm lease time còn bao lâu.

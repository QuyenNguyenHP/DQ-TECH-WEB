Đặt vấn đề:
"Làm sao truyền file nhanh và an toàn giữa hai máy trên Internet?"

Câu trả lời nằm ở FTP và SFTP.

Khái niệm

FTP và SFTP

📖 FTP

Giao thức truyền file cổ điển, chạy trên TCP, không mã hóa dữ liệu.

🔒 SFTP

Truyền file an toàn qua SSH, mọi dữ liệu được mã hóa hoàn toàn.

⚠️ Lưu ý
  • SFTP khác FTPS (SFTP dùng SSH).
  • FTP kém an toàn, dễ bị sniffing.
  • SFTP là tiêu chuẩn hiện đại.

Nguyên lý

Cách FTP và SFTP hoạt động

FTP Dùng 2 kết nối: control (port 21) và data (20/random).
Active vs Passive Passive phổ biến hơn vì phù hợp firewall/NAT.
SFTP Dùng 1 kết nối duy nhất qua SSH port 22.

So sánh

FTP vs SFTP

FTP

  • Không mã hóa.
  • Phức tạp với firewall.
  • Nhiều kết nối.
  • Ít dùng trên Internet công cộng.

SFTP

  • Mã hóa toàn bộ dữ liệu.
  • Dễ cấu hình firewall.
  • Chỉ 1 kết nối.
  • Phổ biến trong thực tế.

Kỹ thuật

Cổng kết nối cần nhớ

FTP

  • Control: port 21.
  • Data: port 20 hoặc random.
  • Không mã hóa.

SFTP

  • Port 22.
  • Mã hóa qua SSH.
  • An toàn khi truyền file nhạy cảm.

Khi nào dùng?

  • Internet công cộng: ưu tiên SFTP.
  • Nội bộ legacy: có thể dùng FTP.
  • Luôn tránh gửi password qua FTP.

Case study: quản trị web server

Kết luận:

Đặt vấn đề

Làm sao router biết phải gửi gói tin đi đâu?

Máy tính của bạn gửi dữ liệu ra Internet và dữ liệu phải đi qua:

  • Router gia đình
  • Router của ISP
  • Nhiều router trung gian khác

Cuối cùng mới đến server đích.

Câu hỏi:
Làm sao mỗi router biết phải chuyển gói tin đi đâu tiếp theo khi có rất nhiều mạng khác nhau?

Câu trả lời là Routing (Định tuyến).

Khái niệm

Routing và vai trò của Routing Table

📖 Định nghĩa

Routing là quá trình lựa chọn đường đi tốt nhất cho gói tin từ mạng nguồn đến mạng đích.

  • Thực hiện bởi router.
  • Hoạt động ở Layer 3 (Network Layer).
🔁 Routing vs Switching
  • Switching → trong cùng mạng.
  • Routing → giữa các mạng khác nhau.
🧭 Routing Table

Router sử dụng routing table để quyết định đường đi.

  • Network đích
  • Next-hop
  • Interface
  • Metric (độ ưu tiên)

Nguyên lý

Quy trình định tuyến cơ bản

1. Nhận gói tin Router nhận IP Packet.
2. Đọc IP đích Xác định địa chỉ IP mục tiêu.
3. So khớp So khớp với routing table.
4. Chọn tuyến Chọn tuyến đường phù hợp nhất.
5. Chuyển tiếp Chuyển packet sang router tiếp theo.

📌 Router không quan tâm MAC cuối, chỉ quan tâm IP Network.

Default Route

Dùng khi không có route cụ thể.

Ký hiệu:

0.0.0.0/0

👉 “Không biết đi đâu thì đi theo đường này”.

So sánh

Static Routing vs Dynamic Routing

🧊 Static Routing

Khái niệm: Route được cấu hình thủ công, không tự động thay đổi.

Phù hợp:

  • Mạng nhỏ
  • Route mặc định
  • Lab, test
⚡ Dynamic Routing

Khái niệm: Router tự động học route thông qua routing protocol.

Ví dụ:

  • RIP
  • OSPF
  • EIGRP
  • BGP

Ưu điểm / Nhược điểm của Static Routing

Ưu điểm Nhược điểm
Đơn giản Không linh hoạt
Bảo mật Không tự thích nghi
Ít tài nguyên Khó quản lý khi mạng lớn

Ưu điểm / Nhược điểm của Dynamic Routing

Ưu điểm Nhược điểm
Tự động Phức tạp
Linh hoạt Tốn tài nguyên
Phù hợp mạng lớn Cần kiến thức

So sánh tổng hợp

Tiêu chí Static Dynamic
Cấu hình Thủ công Tự động
Mở rộng Kém Tốt
Phản ứng khi lỗi Không Có
Độ phức tạp Thấp Cao
Ứng dụng Mạng nhỏ Mạng lớn

Ví dụ

Case study: chọn loại định tuyến phù hợp

Case 1: Mạng văn phòng nhỏ

  • 1 router
  • 2 network
  • Static Routing
  • Đơn giản, dễ kiểm soát

Case 2: Mạng doanh nghiệp / ISP

  • Hàng chục router
  • Nhiều đường dự phòng
  • Dynamic Routing
  • Router tự học đường, tự chuyển hướng khi có sự cố

Thực hành

Tổng kết & bài tập

Tổng kết kiến thức:

  • Routing = chọn đường đi cho gói tin.
  • Router hoạt động ở Layer 3.
  • Routing Table quyết định đường đi.
  • Static: đơn giản, thủ công.
  • Dynamic: tự động, linh hoạt.
  • Routing là xương sống của Internet.

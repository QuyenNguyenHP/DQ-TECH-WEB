Đặt vấn đề

Làm sao nhiều thiết bị dùng chung một IP Public?

Gia đình bạn có:

  • 1 modem / router
  • Nhiều thiết bị: laptop, điện thoại, TV

Nhà mạng chỉ cấp 1 IP Public.

Câu hỏi:
Làm sao nhiều thiết bị private cùng truy cập Internet thông qua 1 IP Public duy nhất?

Câu trả lời là NAT.

Khái niệm

NAT là gì và vì sao cần NAT?

📖 NAT là gì?

NAT (Network Address Translation) là công nghệ chuyển đổi địa chỉ IP Private ↔ IP Public.

  • Thực hiện trên router hoặc firewall.
  • Hoạt động ở Layer 3 & Layer 4.
✅ NAT giúp
  • Tiết kiệm IPv4.
  • Tăng bảo mật cơ bản.
  • Kéo dài tuổi thọ IPv4.
❓ Vì sao cần NAT
  • IPv4 cạn kiệt.
  • Số thiết bị tăng nhanh.
  • Không thể cấp IP Public cho mọi thiết bị.

👉 NAT là giải pháp tạm thời nhưng cực kỳ hiệu quả.

Nguyên lý

Cách NAT dịch địa chỉ

1. Gửi ra ngoài Thiết bị private gửi packet ra Internet.
2. Dịch địa chỉ Router thay IP nguồn Private → IP Public.
3. Lưu bảng Router lưu thông tin vào NAT Table.
4. Nhận phản hồi Server Internet trả dữ liệu về IP Public.
5. Dịch ngược Router dịch ngược → IP Private ban đầu.

📌 Người ngoài không thấy IP nội bộ.

NAT Table lưu:
  • IP Private
  • IP Public
  • Port (nếu có)

Giúp router gửi dữ liệu đúng thiết bị.

Các loại NAT

Static, Dynamic và PAT

a. Static NAT

1 IP Private ↔ 1 IP Public (cố định).

Dùng cho:

  • Server nội bộ
  • Camera
  • Web server

b. Dynamic NAT

IP Private ↔ IP Public (lấy từ pool).

📌 Ít dùng trong gia đình.

c. PAT (NAT Overload)

Nhiều IP Private → 1 IP Public.

Phân biệt bằng Port.

📌 Đây là NAT phổ biến nhất hiện nay.

d. So sánh nhanh

Loại NAT IP Public Số thiết bị
Static 1 1
Dynamic N ≤ N
PAT 1 Rất nhiều

Ví dụ

Case study: Mạng gia đình

Router có IP Public: 113.x.x.x

Thiết bị:

  • Laptop: 192.168.1.10
  • Phone: 192.168.1.20
Quá trình:
  • 192.168.1.10:5000 → 113.x.x.x:40001
  • 192.168.1.20:5001 → 113.x.x.x:40002

👉 Router dùng PAT để phân biệt.

Thực hành

Tổng kết & bài tập

Tổng kết kiến thức:

  • NAT chuyển IP Private ↔ Public.
  • Giải quyết bài toán cạn IPv4.
  • NAT tạo lớp bảo mật cơ bản.
  • PAT là loại NAT phổ biến nhất.
  • IPv6 không cần NAT.

Không có NAT → Internet IPv4 không tồn tại đến hôm nay.
